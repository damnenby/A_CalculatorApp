# Calculator app

Small calculator app for the Mobile Systeme exercise.

It can do normal calculations with +, -, *, / and also more than two numbers.
The result can be used again for the next calculation.

Functions:
- C clears everything
- CE deletes the last input
- +/- changes the sign
- MR and MS are for memory
- long click on MR/MS uses the second memory slot
- sin, cos, tan and sqrt are in the menu
- on tablets the scientific buttons are visible directly

The app is written in Java with XML layouts.
For calculating expressions it uses exp4j.
